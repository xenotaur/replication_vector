# EV-0005: Existing Scene Wired to Velumin Downstream Frame API

## Summary
- Updated Replication Vector to use Velumin's downstream frame API for the first project-owned scene.

- The scene remains the `WI-RENDER-0001` parent probe outline, asteroid outline, shield arc, and projectile line.
