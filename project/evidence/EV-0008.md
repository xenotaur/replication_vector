# EV-0008: Deterministic Parent-Probe Replay Artifact Path

## Summary
- Added a fixed deterministic parent-probe motion replay that uses the Rust simulation model.
- Added a Velumin browser harness path for rendering replay-derived parent-probe pose.
- Added an opt-in local replay smoke command that saves inspectable PNG/JSON artifacts under the ignored smoke output path.

## Evidence
- PR: `https://github.com/xenotaur/replication_vector/pull/14`
- `replication_vector/src/simulation.rs` defines `deterministic_parent_probe_replay()` and records replay samples produced by `step_parent_probe_motion(...)`.
- `replication_vector/src/lib.rs` converts the replay's final `ParentProbeState` into Velumin-facing vector command data and exposes a WASM `replication_vector_replay_frame()` path.
- `replication_vector/web/index.html` renders the replay through Velumin's `WebGPU.renderFrame(frame)` path when loaded with `?scene=replay`.
- `replication_vector/web/render-smoke.mjs` can capture either the existing first scene or the replay scene and writes scene-specific PNG/JSON artifacts.
- `scripts/render-replay-smoke` builds the browser baseline and saves:
  - `replication_vector/web/smoke-out/replay.png`
  - `replication_vector/web/smoke-out/replay.json`
