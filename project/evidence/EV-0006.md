# EV-0006: Opt-in Render Smoke Artifact Capture

## Summary
- Added `scripts/render-smoke` as a local, opt-in command for capturing the Velumin-rendered first Replication Vector scene.
- The command rebuilds the Rust/WASM/Vite browser baseline, starts the Vite harness, waits for `Velumin rendered 4 scene commands`, and captures the `#scene` canvas through Playwright.
- Generated artifacts are written under ignored `replication_vector/web/smoke-out/` paths, not committed.

## Evidence
- `scripts/render-smoke` delegates the build step to `scripts/baseline` and then runs the web smoke capture.
- `replication_vector/web/render-smoke.mjs` drives a WebGPU-capable Chromium, skips clearly when no WebGPU adapter is available, and writes:
  - `replication_vector/web/smoke-out/first-scene.png`
  - `replication_vector/web/smoke-out/first-scene.json`
- `.gitignore` now ignores `**/smoke-out/`.
- `scripts/README.md` documents the command, generated artifact paths, and WebGPU skip behavior.
- `replication_vector/web/package.json` and `package-lock.json` include the Playwright dev dependency needed for local capture.

## Local Capture
- Command run: `scripts/render-smoke`
- Result: passed.
- Screenshot: `replication_vector/web/smoke-out/first-scene.png`
- Metadata: `replication_vector/web/smoke-out/first-scene.json`
- Metadata captured:
  - command count: `4`
  - status: `Velumin rendered 4 scene commands`
  - viewport: `1024x768`
  - Velumin checkout: `3e64bce`
- Visual inspection confirmed the saved screenshot contains the parent probe outline, asteroid outline, shield arc, projectile line, and status text.

## Result
- Proven: Replication Vector can save a repeatable local inspection artifact for the existing Velumin-rendered scene.
- No Velumin API gap was discovered for this work item.
- Remaining risk: this is intentionally not a mandatory CI visual regression gate and does not compare against committed golden screenshots.
