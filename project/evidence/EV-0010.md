# EV-0010: Deterministic Matter-Resource Mining Boundary

## Summary
- `WI-MINING-0001` is resolved and adds the first Rust-owned matter resource boundary.
- Implementation commit: `8a08f51`; PR: `https://github.com/xenotaur/replication_vector/pull/21`; merge commit: `f43a55dbd16e9262e009d76124e7ac5ff688fd48`.
- `step_mining(...)` transfers matter only for active input and an explicit source range, using a fixed rate and timestep.
- Source depletion and parent storage capacity clamp the transfer; the boundary also normalizes malformed public resource state before stepping.
- Existing first-scene, replay, and parent-probe tuning sandbox paths remain unchanged.

## Evidence
- `replication_vector/src/simulation.rs` defines `MatterStorage`, `MiningSource`, `MiningInput`, `MiningConfig`, `MiningStepResult`, and `step_mining(...)`.
- Focused tests cover active in-range transfer, inactive and out-of-range no-op behavior, source depletion, parent capacity, malformed storage normalization, and repeatability across fixed steps.
- `scripts/README.md` documents the Rust-only mining validation path and the existing Velumin sandbox path.

## Browser/WebGPU Verification
- `scripts/baseline` passed, rebuilding the Rust/WASM/Vite browser baseline.
- `scripts/render-smoke` passed with `Velumin rendered 4 scene commands`; artifact and metadata were written to ignored local `replication_vector/web/smoke-out/first-scene.{png,json}`.
- `scripts/render-replay-smoke` passed with `Velumin rendered 4 replay commands`; artifact and metadata were written to ignored local `replication_vector/web/smoke-out/replay.{png,json}`.
- `scripts/render-sandbox-smoke` passed with `Velumin rendered 3 sandbox commands`; artifact and metadata were written to ignored local `replication_vector/web/smoke-out/sandbox.{png,json}`.
- The first sandboxed smoke attempts hit the known `wasm-pack`/`wasm-opt` `Operation not permitted` setup boundary; rerunning with the required elevated environment completed successfully.
- No mining browser UI or alternate renderer was added; the existing sandbox remains available for parent-probe and static-asteroid inspection.

## Result
- Proven and landed: one deterministic Rust simulation boundary can transfer matter from a range-gated source to parent storage with inactive, depletion, capacity, and repeatability behavior covered by tests.
- Proven: existing Velumin scene, replay, and tuning sandbox paths still build and render.
- Deferred: collision, shields, enemies, child probe, scoring, progression, game-over, mining browser controls, economy systems, broad visual-regression infrastructure, and alternate renderers.
